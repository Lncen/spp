## 启动所有
```shell
docker compose up --build
```
- 只启动后端
```shell
docker-compose up -d --build backend
```

## 启动开发服务器
```shell
docker compose watch
```


## 生成密钥
```shell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

## 安装所有依赖
```shell
uv sync
```


## 查询prestart错误
```shell
docker compose logs prestart --tail=100
```

## 数据库生成迁徙文件（D:\code\fa_shop\backend 执行）
```shell
cd backend

alembic revision --autogenerate -m "init system"

alembic upgrade head
```

## 初始化数据库
```shell
alembic init alembic
```


## 提交前检查代码 对项目中所有文件进行一次完整的检查和格式化
```shell
uv run prek run --all-files
```
